# 微博竖屏布局

一个油猴脚本，把微博网页版（weibo.com）改成适合竖屏的推特式布局。

- **左侧细导航栏**：原来约 180px 宽的导航收成 72px，只显示图标和一行小字。自定义分组显示为名字首字的圆形图标，鼠标悬停显示全名，点击切换分组的功能不变。
- **正文铺满**：中间信息流占满剩余宽度（最大 900px），去掉右侧栏。视频封面限宽 640px，避免变得太大。
- **精简顶栏**：只保留「首页」「消息」和头像，去掉「推荐」「视频」。
- **热搜 Top10**：顶栏多了一个 🔥 按钮，点它或按 `H` 键，热搜从右侧滑出。广告已过滤，点条目会在新标签页打开搜索结果，按 `Esc` 或点抽屉外面关闭。

## 安装

1. 在浏览器里安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [weibo-portrait.user.js](https://raw.githubusercontent.com/Havadking/weibo-portrait/main/weibo-portrait.user.js)，Tampermonkey 会弹出安装页，点「安装」即可。
3. 刷新 weibo.com。

脚本里配置了 `@updateURL`，Tampermonkey 会按它的检查周期自动更新到最新版。

> 如果之前用 Stylus 等扩展给微博加过自定义样式，请先停用，否则可能和脚本冲突。

## 实现说明

- 微博用的是带构建哈希的 CSS Modules 类名（如 `_side_1ubn9_37`）。脚本只匹配前缀（`[class*="_side_"]`），并通过 `#app > [class*="_wrap_"] > [class*="_content_"]` 这样的层级限定范围，所以微博重新发版后一般仍然有效。
- 热搜数据来自微博网页版自己用的接口 `/ajax/side/hotSearch`。请求是同源的，会自动带上登录态，不需要额外的 `@grant` 权限。结果缓存 2 分钟。
- 顶栏的热搜按钮是复制「消息」按钮再换掉图标做出来的，所以样式和顶栏其他按钮一致。
- 热搜抽屉会读取微博面板的背景色和文字色，跟随站内的深色/浅色模式。

`mockup.html` 是最初讨论布局时用的静态设计稿。

## 失效了怎么办

微博改版后如果样式错乱，打开开发者工具（F12）检查左侧导航和正文容器的类名前缀，对照脚本开头的 `LAYOUT` / `TOP` / `SIDE` 常量修改；也欢迎提 issue。
